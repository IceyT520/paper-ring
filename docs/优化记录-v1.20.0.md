## 本版变化

- 第五章增加四个阅读标题：渴望持续的回应、为什么会更用力、追问背后的恐惧、当爱承载了救赎。标题在原文之外，71 个正文块与 37 项校订不变。

- 结语到参考章节逐渐降低背景红蓝光色，桌面结语的小纸环淡化；大字结语、献给爱、宋体致谢保留。无 WebGL 电影 SVG 改为接近中性纸材的色阶。
- 开篇导语明确作者亲身经历的出发点；四篇文献各附研究主题，原始文献条目与作者论述保持。
- 修正 release.mjs 日志：该命令只 render→package→check，不更新 dist、不跑 tsc/单测；移除建议 git add -A 的日志。

## 一并修正的定位问题

旧 sourceObserver 只比较本批进入观察区段落的顶边与屏幕 30% 位置。切换为全文模式后，段落行数变短，即使阅读线仍在原段内部，下一段的顶边也可能更近；随即返回展览便定位到下一段。

现在在观察器通知时读取当前模式中段落的实际范围，优先选择包含阅读线的段落。该测量不在逐帧滚动处理里运行。新增浏览器回归从第七章第三小节切换两种阅读模式，要求返回原小节；并覆盖逆向跳节、键盘导航和导航避让。

## 检查与边界

新增 `website/scripts/qa-reading-flow.mjs --offline`，已纳入 Pages workflow。它还覆盖 α/D 在预设、参数、模型切换和重置后的实际数值与说明。

本地已通过 16 项单元测试、类型检查/生产构建、离线打包和正文核对，以及 reading-flow、typography、narrative、simulator、text-motion、finale、offline、alignment 浏览器检查。电影检查串行运行。桌面画面检查采用 1440×1000 与 1366×768。现有多宽度回归只防止共同修改破坏布局，不代表本版做了手机专项优化。远程部署状态以对应 commit 的 Actions 为准。
