# v1.20.1 接手补充

日期：2026-10-28（Asia/Shanghai）。用户要求：小节导航与原页面融为一体；大标题以白色为主体，不再整块全蓝或全红。

## 当前规则与实现

- 第七章桌面常驻小节入口融入原顶栏中间区域，替换英文展览说明；离开该章或进入全文阅读模式，恢复原说明。文字沿用顶栏的小字号与灰白色，当前小节只有细白线提示。
- 正文中的六节概览保留在正常阅读流里，删除 v1.20.0 新增的第二条实底吸顶横栏。滚动定位只避让原顶栏，左侧场景恢复原来的顶部位置。
- 大标题与各级阅读标题统一纸白基色。第 04、05、07、08、09 章仅在“靠近”“失去”“隔着”“清晰”“一起走”等短语上点缀红蓝；沙盘和纸环总结也缩小着色范围。
- 保留“手机亮起”四字红色、白色句号，以及共同表面的红蓝纸白渐变。图形中的焦虑红／回避蓝、两句底线、消息配色不变。
- **以上为最新偏好，替代旧交接中“允许整标题红蓝”及 v1.20.0 独立吸顶导航的描述。** 手机专项仍不在本次范围内。

## 验证

导航回归覆盖当前节标记、键盘跳节、顶栏避让、全文往返定位、离开第七章、1100px 边界及窄桌面与全局按钮不重叠。标题检查覆盖纸白基色、局部强调与原有宋体致谢。实际画面检查包括 1440×1000 与 1101×768。

本地已通过 16 项单元测试、生产构建、正文完整性核对，以及 reading-flow、typography、narrative、text-motion、offline 浏览器检查。
