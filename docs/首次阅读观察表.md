# 《纸环的两面》首次阅读观察

适用版本：v1.16.0。邀请 3–5 位没有参与制作的人，分别使用自己的设备阅读。
这是一份待使用的观察表，不代表已经完成真实读者测试。

## 开始前

给读者同一个在线链接，请对方按自己的意愿阅读。不要提前解释屋檐、纸环、红蓝或预期结论。
不要求完成所有互动，不催促读完。经对方同意后记录观察；无需收集真实姓名和感情经历。

## 阅读后的中性提问

1. 现在最记得的三个画面是什么？为什么记得？
2. 你觉得屋檐这一段想表达什么？
3. 你觉得最后纸环的变化想表达什么？两者有什么联系？
4. “独处时补上一句”的互动，前后有什么变化？
5. 有没有哪个场景让你觉得意思已经讲过，或者还没讲清？
6. 哪个时刻让你觉得作品快结束了？之后的内容感觉如何？
7. 如果只改一处，你希望改哪里？

## 汇总原则

先保留原话，再记录观察者解释；不要把自己的推测写成读者结论。
重复出现的理解困难和操作障碍优先修改。少数读者的个人偏好单独保留。
若屋檐被理解为“消除差异”，或莫比乌斯被理解为“失去自我”，回看图形与文字的实际表达。
如果读者理解了含义却不想操作，应先检查节奏与必要性，不立即增加操作步骤。
