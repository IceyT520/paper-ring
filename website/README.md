# 纸环的两面

一场关于亲密关系的十二幕交互展览。正文来自上级目录的原始 PDF。

v1.18.0：纸白为主，按双方与连接的含义增加红、蓝、金及渐变。结尾纸环使用真实几何投影适配完整轮廓，独立放映中的画面、字幕、控件分别占位，矮横屏采用左右构图。全站阅读文字与互动替换采用淡入淡出，连续操作保留最后一次选择；开场重播与跳过也衔接文字透明度。`qa-text-motion.mjs` 验证这些过渡，`paper-framing.test.ts` 独立检查所有电影姿态与多种宽高比下的纸带投影。

十二章处于同一个连续的深色光影空间，红蓝纸线贯穿全文。莫比乌斯环在解结之后展开，依次打开、扭转、重连，支持重播、旋转和键盘操作。结语标题为“回到爱的本身”，以“CONCLUSION / 结语”标明收束，书末为“原文与参考”。

首屏有约 8 秒的开场：侧光先勾出纸环，纸面缓慢转正，红蓝细线从不同方向展开，标题分两拍显现，随后补全副标题和阅读提示。结束后清除所有临时样式，恢复原有构图；纸环及光点定格，首屏停止持续三维绘制。首屏右下角原版本号的位置改为共用控制位：播放时显示“跳过动画”，结束后显示“重播开场”。控制位与底部小字共用整行淡入，重播前整行一起淡出。每次播放期间锁住滚轮、触屏滑动、翻页键与章节导航，完成后恢复阅读；可点击“跳过动画”或按 Escape 主动结束。减少动态效果、章节直达和历史返回直接显示完整首屏。后台切换也会结束开场，不会回来后继续等待。动画有 9 秒的完成保障。

开场会先准备三维纸环并完成第一帧绘制，再播放时间线，避免初始化打断已经开始的动作。加载期间不显示平面的纸环占位图；三维不可用时才使用静态示意。网站不提供书签或续读提示，也不保存阅读位置，旧版本留下的书签记录会自动清理；两种阅读模式仍可在当前段落之间切换。

第五章“救赎”部分延续前文背景、字色和行宽，以短线和小字提示转折。正文旁的章节标题左对齐；独立金句、图注、结语与致谢标题居中，标题上方的章节标识跟随同一对齐方式。

第三章“同一个起点，不同的保护方式”采用两件有折痕与侧光的纸褶装置：蓝色向内收拢，红色向外舒展。轻触中间的暖光，两件装置放平为相同的结构，露出同一句“想被爱”；再次轻触可回看两种保护姿态。原有线条图与三个颜色切换按钮已移除。首次进入只播放一次，返回保留读者选择；有限的 CSS 变换完成后停止，没有新增三维渲染器或持续动画。

致谢的手机场景保留右侧“今天也很想你。”，屏幕亮起后，左侧出现对方回复“我们见一面吧”。这是用户指定的情境对话，原文致谢保持完整；减少动态效果时直接呈现完整对话。

第四章的防御装置是一件有正反两面的折纸：鼠标移向中央，或轻触折页、点击“靠近一点”，两侧六道折页会合拢，遮住写着“想靠近”的纸片。冷蓝侧光随靠近加强，折页投影随纸面转动，内部暖光收窄成一道缝。点击“绕到墙后”，整件折纸转向背面，暖光照亮“我也想被理解”及防御背后的恐惧。折页与纸片使用真实的 CSS 三维遮挡，光影变化对应防御与被保护的需要。`src/defense.ts` 独立管理姿态，不再与滚动动画共同写入变换。触屏、键盘、减少动态效果和 WebGL 不可用时均能操作。

独立居中标题在字体加载与窗口变化后，按每行字形的实际边界进行视觉校正；标点保留并悬挂在正文文字旁，末尾字距也纳入计算，避免容器居中但文字向左偏。手机端的长金句按语义分行。测量不参与滚动或动画帧，JavaScript 不可用时保留常规居中排版。

当前交互直接发生在画面中的物件上：捏住信纸向右投出；叩击纸面，让呼唤留下回声，再把蓝色的“我在”交还给它；在两条独立轨迹之间缝下四个约定；轻触真实的三维纸面，让一束光走过曾经的两面。上述场景的参数拖条已经移除，数学沙盘仍保留距离和系数控件。所有新动作均有可聚焦按钮，触屏、键盘和减少动态效果模式可以使用。

信件按接收框的实际中心、旋转角和尺寸落位，窗口变化后保持对齐。“一起走”的针脚端点与红蓝纸带共用曲线坐标，控制钮放在图形下方；下方两处交点由同一组曲线生成。纸环保持轻微浮动，放光不会带动整环快速自转；光的完整行程为 24 秒，形态重播为 9 秒。形变只通过“播放这次连接”、三个阶段按钮或“放下一束光”触发，支持暂停与继续；阶段切换不会移动页面，滚动、窗口变化和动态模式切换不会改写所选进度。未连接时轻触纸面仅提示使用按钮，完成后轻触仍可放光。装置保留原有大幅构图，移除用于滚动推进的长停留区间。

## 直接观看

双击仓库根目录的 **纸环的两面.html**。字体、样式、脚本和三维组件均已内嵌，无需联网或安装依赖。

将它与同目录的 **纸环的两面.pdf** 一起保存，即可使用原始 PDF 的打开和下载入口。网站本身的全部正文已经内嵌，独立保存 HTML 也不会丢失正文。

## 开发与部署

使用 Node.js 22.12+，pnpm：

```sh
pnpm install
pnpm dev
pnpm build
pnpm test
pnpm check:content
pnpm package      # 打包单文件成品 纸环的两面.html
pnpm release      # 重新生成页面 + 打包 + 校验（发布前跑这一条）
```

`dist/` 为可部署至普通静态托管的产物。无账户、数据库或服务端依赖。也可运行 `node scripts/serve.mjs` 在本地预览生产构建。

发布用的文件名单一来源在 `scripts/paths.mjs`：单文件成品固定写到根目录 `纸环的两面.html`，`--offline` 验收脚本与打包脚本都从它取路径，不要再各自写文件名。

## 内容与修改

- `content/article.json`：71 个原文阅读块，包含原章节、PDF 页码、原文偏移、展示章节和独立编者注。所有块拼接后完整重建提取文本。
- `content/corrections.json`：用户授权的逐项校订，记录原句、修改及原因。原始提取文本和 PDF 不覆盖，两种网页阅读模式同时应用这一份校订。
- `scripts/extract-content.py`：从上级目录 PDF 重新提取内容，需要 Python 和 `pypdf`。先修改 PDF 才需要重新提取；正常构建无需 Python。
- `scripts/render.mjs`：静态生成十二幕展览及原文阅读模式。内容保持在 HTML 中，不依赖客户端运行脚本。
- `scripts/journey-art.mjs`：文章意象的 SVG 图形与莫比乌斯场景结构。
- `src/journey.css`、`src/touch.ts`：连续背景、阅读排版，以及投信、回声、缝线等直接操作。
- `src/typography.ts`：居中大字的逐行字形测量、标点悬挂与窗口变化后的重新对齐。
- `src/opening.ts`：首屏灯光、纸环姿态、红蓝线与标题的可重播编排，播放期间锁住阅读，完成及中断后恢复静态构图和滚动。
- `src/origin.ts`：两种折纸保护姿态、暖光揭示和首次进入时的有限动画。
- `src/audio.ts`：背景音乐（`public/theme.mp3`，《唯一》）。与拆信同一手势开始、淡入到 30%、单曲循环，♪ 可开关并记住选择。线上只预读元数据、拆信时才下载；`pnpm release` 把音频以 base64 内嵌进单文件（运行时转 blob），所以成品单独发出去也有声。没有文件时控件隐藏、展览静音。
- `src/gate.ts`：开场前的信封。轻触拆封（蜡封开裂、信纸抽出）以取得用户手势，同一手势里启动音乐并放行开场；带 `#` 的深链、前进/后退与 `?nogate=1` 会跳过它。没有 JS 时信封保持 `hidden`，正文照常可读。
- `src/`：视觉样式、交互、三维纸带及独立数学模型。
- `scripts/fetch-fonts.py`：仅制作时下载字体子集。字体文件随网站保存；正文或 UI 字符显著变化后可重新运行。

依恋叙述保留作者观点。明显笔误直接修正；模型解释按保留的方程校正，包括反比例距离项、临界平衡线及不产生周期振荡。原文线性方程使用解析解，不截断到 [0,1]；有界扩展采用独立标记的饱和假设和 RK4 积分。数值超过 10,000 时结束当次绘图并明确说明，保留实际采样值。

`qa-opening.mjs` 检查桌面与手机开场在 10 秒内结束，标题恢复原有位置，纸环连续两次截图一致且 WebGL 不再绘制；同时覆盖跳过、滚动锁定、动态开关、减少动态效果、章节直达和三维不可用时的降级。`--offline` 在本地独立 HTML 上执行同样检查。截图记录开场初段、中段与定格画面，报告为 `test-results/opening-report.json` 与 `opening-offline-report.json`。

`qa-startup.mjs` 延迟三维模块加载，逐帧确认加载期间没有平面占位图闪现，开场时间线在第一帧纸环绘制完成后才运行。

`qa-origin.mjs` 在 360、390、768、1440 像素宽度检查两种纸褶的实际展开幅度、放平后的同形结构、内层文字显露、键盘切换、返回时保持状态和动画停止；支持 `--offline` 验证独立 HTML。

## 性能

滚动不再修改文章根节点的继承变量；光色只更新两个独立背景层的透明度。章节位置在布局变化时缓存，阅读进度使用合成变换，SVG 插图整体显现，避免每条曲线随滚动反复绘制。

纸带网格从每面 6,160 个三角形减至 576 个，使用解析法线和固定包围球，并将同一帧中的几何更新合并。三维画布限制总像素；已取消 30fps 限制，活动场景按浏览器动画帧实际绘制，高刷新率屏幕也不会被人为跳帧。运动速度与帧率分离，使用时间阻尼，不再将形变进度量化为 500 档。暂停、离屏和后台停止无用渲染。彩线仍印在纸面材质上，光点沿真实表面移动；形变完成后才启动跨面的光路。

`scripts/profile-scroll.mjs` 测量页面的滚动和样式计算，历史数据保留在 `test-results/performance-*.json`。这些页面帧间隔不能用来证明三维画布的实际帧率。

本轮另用 `scripts/profile-paper.mjs` 记录纸环画布的实际 WebGL 绘制，在同一本机 Edge 无头环境、1440 × 1000 视口、无 CPU 限速下采样 4 秒。原始数据为 `test-results/paper-cadence-before.json` 与 `paper-cadence-after.json`。实际表现取决于设备和屏幕刷新率。

| 三维绘制 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 实际绘制频率 | 30.0fps | 142.9fps |
| 绘制间隔 P95 | 33.9ms | 12.6ms |
| 绘制帧 / 浏览器动画帧 | 12.6% | 100% |

`qa-alignment.mjs` 从浏览器中实际生成的 SVG 路径和 DOM 矩阵检查几何关系，覆盖四种宽度及发送后窗口变化：信与框中心误差低于 1px、四组针脚连接到各自曲线、全部红蓝曲线经过两个标记交点，按钮不与线条重叠。结果记录在 `test-results/alignment-report.json`。
